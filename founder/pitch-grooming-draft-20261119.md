# Borrador anterior conservado

Primer borrador orientado a peluquería, preparado antes de que Andrés confirmara evaluar también centros/clínicas veterinarias y pet shops. No se ejecutó un panel con este mensaje.

Huella Nex es una aplicación web para gestionar clientes, mascotas, agenda, atención y caja de tu peluquería.
La propuesta de prueba evalúa el dashboard manual estándar con acompañamiento; no incluye WhatsApp ni IA.
La referencia por evaluar es $49.000 COP al mes por establecimiento; precio final, impuestos y condiciones quedan por confirmar.
Puedes solicitar una evaluación asistida con datos ficticios al responsable del proyecto antes de decidir si el producto encaja.
Si necesitas atender una sola mascota a la vez, existe una brecha de control de capacidad que debemos resolver o reconocer antes de admitir ese uso.
Periodo gratuito, soporte y uso de datos reales se acuerdan expresamente; este mensaje de investigación no inicia una suscripción.
